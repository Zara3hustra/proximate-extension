# Разбор сессии: промо-ролик Proximate (HyperFrames)

Живой чеклист понимания. Отмечаем по мере того, как осваиваешь.
Статусы: ⬜ не начато · 🟡 в процессе · ✅ освоено

## 1. Проблема / мотивация
- ✅ Зачем видео из HTML, а не AE/Canva — автоматизация: один шаблон → подмена → N роликов (выигрыш времени)
- ✅ Что такое «детерминированный рендер» — определено входом, тот же вход→тот же выход (НЕ про качество/скорость)
- ✅ Почему HyperFrames «для агентов» — ролик это код: промпт→git→перегенерация (variables/--variables)
- ⬜ Почему для промо выбрали тёмный tech-стиль, а не светлый UI расширения

## 2. Решение / как устроено
- ⬜ Структура композиции: один root `data-composition-id`, одна GSAP-таймлиния
- ⬜ Контракт таймлинии: `paused`, регистрация в `window.__timelines`, длительность из `data-duration`
- ⬜ Сцены как div'ы, управляемые таймлинией (а не отдельные «клипы»)
- ⬜ Правило переходов: только entrance-анимации, без exit (кроме финала); переход = «выход»
- ⬜ Детерминизм: почему нельзя `Math.random()`/`Date.now()`/`repeat:-1`
- ⬜ Layout-before-animation: зачем строить финальный кадр до анимации
- ⬜ `data-layout-ignore` на декоративах и почему ghost-текст «провалил» контраст намеренно

## 3. Контекст / почему это важно
- ⬜ Что детерминизм даёт в CI/повторяемости (принцип студии «системное > разовое»)
- ⬜ Как переиспользовать это под Specmix/CartridgeBuy (variables, варианты)
- ⬜ Что меняется в воркфлоу: видео теперь в git рядом с продуктом, правится текстом
