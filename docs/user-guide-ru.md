# Proximate — инструкция по настройке

Proximate — расширение для Chrome, которое направляет нужные сайты через ваш личный прокси-сервер. Всё остальное (банки, Госуслуги, почта) работает напрямую.

---

## Шаг 1 — Установите расширение

Откройте Chrome Web Store и установите **Proximate**.

После установки иконка 🌐 появится в панели браузера. Если её не видно — нажмите на значок пазла 🧩 справа от адресной строки и закрепите Proximate.

---

## Шаг 2 — Получите данные прокси

Данные для подключения выдаёт Telegram-бот. Если у вас ещё нет доступа — напишите боту и следуйте его инструкциям.

Бот пришлёт строку вида:
```
203.0.113.10:10808
```
или
```
203.0.113.10:10808:логин:пароль
```

Сохраните её — она понадобится на следующем шаге.

---

## Шаг 3 — Введите настройки прокси

1. Нажмите на иконку 🌐 в панели браузера
2. Нажмите ⚙ (шестерёнка) в правом верхнем углу
3. Откроются «Настройки прокси»
4. Заполните поля:
   - **Хост** — вставьте сюда всю строку целиком (`203.0.113.10:10808:логин:пароль`), расширение разберёт её автоматически. Или введите только IP-адрес, а порт, логин и пароль — отдельно
   - **Протокол** — оставьте **Авто**, расширение определит сам
5. Нажмите **Проверить прокси** — должно появиться: `✓ Прокси доступен · IP: 203.0.113.10 · Страна: DE`
6. Нажмите стрелку ← чтобы вернуться

---

## Шаг 4 — Включите расширение и выберите сервисы

1. На главном экране переведите верхний тумблер в положение ВКЛ — статус изменится на **Активен**
2. Нажмите на нужные сервисы, чтобы включить маршрутизацию через прокси:

| Сервис | Что даёт |
|---|---|
| Gemini | Google Gemini — AI-чат |
| AI Studio | Google AI Studio |
| NotebookLM | NotebookLM от Google |
| Google Labs | labs.google |
| ChatGPT | chat.openai.com |
| Claude | claude.ai |
| Perplexity | perplexity.ai |
| Grok | grok.com |
| ElevenLabs | elevenlabs.io |

Включённые сервисы подсвечиваются. Остальные сайты продолжают работать напрямую.

---

## Шаг 5 — Проверьте работу

Откройте любой включённый сервис — например, **gemini.google.com**. Иконка расширения должна стать зелёной.

На обычных сайтах (Яндекс, VK, банки) иконка остаётся серой — трафик идёт напрямую, без прокси.

---

## Значения иконки

| Иконка | Цвет | Что происходит |
|---|---|---|
| 🌐 серая | off | Расширение выключено |
| 🌐 синяя | direct | Сайт идёт напрямую |
| 🌐 зелёная | routed | Сайт идёт через прокси |
| 🌐 красная | error | Ошибка подключения |

---

## Добавить свой домен

Если нужно пустить через прокси сайт, которого нет в списке:

1. На главном экране найдите раздел **Свои домены**
2. Введите домен в поле: `example.com`
3. Нажмите **+ Добавить**

Поддерживаются форматы:
- `example.com` — только этот домен и все поддомены
- `*.example.com` — явно только поддомены
- `=example.com` — только точное совпадение

## Часто задаваемые вопросы

**Сервис включён, но сайт не открывается**
→ Нажмите ⚙ → **Проверить прокси**. Если ошибка — убедитесь, что хост и порт введены верно.

**Нужно ли держать расширение включённым постоянно?**
→ Да, но это не влияет на скорость обычных сайтов — они всё равно идут напрямую.

**Работает ли на других браузерах?**
→ Только Chromium-браузеры: Chrome, Edge, Brave, Opera.

**Как временно отключить**
→ Переведите верхний тумблер в положение ВЫКЛ — всё вернётся к обычному соединению.

**Утечка IP через WebRTC**
→ При использовании SOCKS5 WebRTC может раскрыть реальный IP. Для полной защиты используйте HTTP-протокол в настройках прокси.
